# Analog +0x18 is status — 2026-09-21 0055 boot

Hyprland: eDP-1 only. Tunnel kept, DPRX=0.

## Dump then write

First analog dump (before any analog write):

```
dpin0 +0x18=00001017   live status (0x17 plus bit 12 vs 0054's 0x17)
dpin0 +0x00=80000000
dpin0 +0x20 skipped (zero)
```

Then `+0x18 wrote 0x1f readback 0x80000000`. The write did not stick.
A second read of `+0x18` after the dump already returned `80000000`,
so this register is status (read-to-clear or read-only overlay).

## Closed

Driving analog `+0x18` as a control FSM. DPME still does not set DPRX.

## 0056

Do not write `+0x18`. Pulse analog `+0x00` bit 0 even when readback is
`80000000` (write-1 start, status overlay). Fill `+0x20` if it is 0
(idle dpin1 has that field; active dpin0 does not). Dump analog with
zeros so the hole is visible.
