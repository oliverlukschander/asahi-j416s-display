# 0070 supports_hpd connect — same bind, no DPRX

```
validate atc=0: 0
connect atc=0 HPD: 0
set_hpd: 0
```

eDP on. No `unexpected unk`, no `device == NULL`. Analog timeout
`+0x18=0x17` (0069 had 0x1016; that bit 12 is transient). DPRX=0.

Firmware DPTX devices on j416s: ATC 0–2, HDMI PHY 3, lpdptxphy 4.
`0x9000` (ATC=0 DPIN=1) is an AFK remote port with no DPTXController
device. Further 0x9000 flag tweaks will not create one.
