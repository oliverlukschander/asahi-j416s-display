# Live: nub_spmi0 and ACIO during DCPDPDevice start

Same 0085 boot, hub in, eDP on. Re-armed the USB4 path several
times. `DCPDPDevice` still dies at 5 s with `0xe0115022`.

`nub_spmi0` (`0x29e280000+0x60`) is the only SoC PMGR register
that changes at start: `0x1400024f` (clock-gated) to `0x1f0002ff`
(active). Holding that active value for the whole 5 s does not
stop the timeout. Readback stayed `0x1f0002ff`. eDP stayed on.
Writing the old value did not stick. Left active.

ACIO RC across the same window: analog `0x4000` does not change.
`0x003c` is a free-running counter. `0x0078` goes `1 -> 3` at
start. `0x0040` ticks `0x3f -> 0x41` by the timeout. The DPTX
device is not programming the DP IN analog PHY.

No `SET_LINK_RATE`. DPRX stays 0. Hyprland eDP-1 only.
