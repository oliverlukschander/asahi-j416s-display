# VSE probe wedged USB4 config space — 2026-09-21 0059

Hyprland: eDP-1 only. `DPRX=1` in the late dump is fake: every CS
word is `ffffffff` so bit 31 (DPRX_DONE / LCK) looks set.

## What happened

VSE +0x02 … +0x0a: write 1 stuck (scratch). Then:

```
Apple VSE +0x0b wrote 1 read ffffffff
Apple VSE cap missing: -110
0:5 CS all ffffffff, hop 8/9 read failed -110
```

USB4 config space timed out after the +0x0b write. NHI/CM path was
dead; existing tunnels may still carry USB. Do not write Apple VSE
+0x02–0x0b.

No `started ep` lines: RTKit 0x10–0x1f did not start.

## 0060

Remove the VSE probe. Dump-only VSE. Abort adapter dumps on
`ffffffff` so a dead NHI does not stall 20 s.
