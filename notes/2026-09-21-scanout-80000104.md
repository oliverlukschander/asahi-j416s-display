# USB4 fake 1080p: 80000104, fDisplayPowerState=0 — 2026-09-21

Kernel `set_digital_out_mode(color:1 timing:2) 1920x1080` on 315c.
Firmware: `set_mode` then `setmode failed`,
`pipe not enabled: fSoftPowerState=1, fDisplayPowerState=0, fHardPowerState=1`,
return `80000104`.

eDP stayed. Hyprland listed USB-3 1920x1080 (Linux marked valid_mode
anyway). DPRX stayed 0.

`iomfb_poweron` on 315c did not set fDisplayPowerState. Next reboot
stuck on the Omarchy logo (power-off to recover). Do not poweron
dcpext that way.

Firmware will not enable the dcpext pipe without a real display power
path (DPTX sink). lpdptxphy provides that and blanks eDP / misses DP IN.
