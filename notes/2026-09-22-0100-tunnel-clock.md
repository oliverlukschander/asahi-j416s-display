initRegisterSpaces9d213d0 and the native atc-phy2 device-tree capture map
object+160 to resource3/core f03000000, +170 to resource4 f03002000,
+180 to resource5 f03002200, +1b0 to resource8 f03007000. These are ATC
core clock registers, not forbidden ACIO RC analog f01ac4000.
Private disassembly remains under ~/.local/share/j416s-display/dpin-static-13.5/.

0100 adds an optional exported operation to the existing ATC owner;
no second mapping and no PHY_MODE_DP operation. DPTX SET_LINK_RATE invokes
it before caching the rate. Guards require both opt-ins, J416s, t6020 ATC,
right resource f03000000, USB4 mode, right source2/DCP2/unit0/die0,
firmware13.5 and DPIN index1. Zero-rate/deactivation uses the saved PHY
pointer even if the route has detached. Mode transitions restore before
existing power-off. Default options are false/read-only.

It refuses existing PCLK1/PCLK2/DPRX clients, enabled PLL outputs, or an
in-flight command. A successful repeated identical rate is a no-op;
a different active rate is refused. Only one programming attempt per
PHY per boot is allowed. This is not full multiport/client arbitration.

Owned masks in existing core f03000000 mapping (offset/mask):
008/3ffff, 1b0/fff, 7000/207c, 2224/3, 2080/ffffffff,
2084/0fffffff, 2088/007fffff, 2208/001f0000, 2220/80,
2214/1, 2200/54, 2000/1ffffff9.
Additional reads: a74 CMD_READY and 7044 AUSPLL_LOCK.
No SS lane mux, CIO3 PLL, ACIO RC, lpdptx, panel or crossbar writes added.
Existing0099 crossbar/native-DPIN instrumentation remains unchanged.

Cleanup stops PCLK1 and PLL outputs, then restores saved owned register
fields in reverse order. This is a bounded register rollback, NOT a full
port of native unconfigureDPTunnelMode, which includes additional shared
client/CIO3 retuning. RAM tests verify the rollback but cannot prove PLL
internal-state restoration or hardware safety. Refusing other clients and
retaining normal mode power-off limits this experiment's scope. Poll timeouts
return errors; they do not get silently treated as successful rate changes.
