# 0072 request_display on CORE=1 (0x9001)

0071 bind:

```
validate core=1: 0
connect core=1 HPD: 0
set_hpd: 0
analog +0x18 = 0x09   (was 0x17 on CORE=0)
DPRX=0, eDP on
```

CORE=1 reached the ACIO analog PHY. Call `request_display` on that
remote port so DPTXController can AUX into dpin0. Still no
lpdptxphy `core+0x10`. Do not HPD-kick if INACTIVE_SINK.

Look for `request_display core=1: 0`, then `SET_LINK_RATE` /
`SET_ACTIVE_LANE_COUNT` / `device == NULL` / DPRX.
