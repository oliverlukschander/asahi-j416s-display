# 0072 request_display on CORE=1 (0x9001)

0071 bind:

```
validate core=1: 0
connect core=1 HPD: 0
set_hpd: 0
analog +0x18 = 0x09   (was 0x17 on CORE=0)
DPRX=0, eDP on
```

CORE=1 reached the ACIO analog PHY. Call `request_display` on that
remote port so DPTXController can AUX into dpin0. Still no
lpdptxphy `core+0x10`. Do not HPD-kick if INACTIVE_SINK.

Boot:

```
AppleDCPDPTX.cpp:355: [AFK]powering nub 0x854e10
APCALL 18 GET_SUPPORTS_HPD
APCALL 10 get_max_lane_count: USB4 DP IN, 4 lanes
APCALL 0 ACTIVATE
request_display core=1: 0
~5.5s APCALL 22/24 DEVICE_NOT_RESPONDING / DEVICE_NOT_STARTED
```

No `device == NULL` (that was 0x9000). Firmware powered a nub and
ACTIVATEd. GET_SUPPORTS_HPD still returned false, so it waited for a
PHY start. Analog `+0x18` back to `0x17` (0071 without request_display
stayed `0x09`). DPRX=0, eDP on.

0073: advertise HPD on USB4 analog DPIN (`GET_SUPPORTS_HPD=1`).
