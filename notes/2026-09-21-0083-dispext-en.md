# 0083 T602x crossbar dispext enable on dpin0

0082: firmware powers nub, `pmgrResetDevice 0x25`, ACTIVATE, then
waits. Analog `+0x18=0x17`. Crossbar dump after `Switched dpin0`
had `050=00000000`.

t8103 sets `CROSSBAR_DISPEXT_EN` (0x050) to the dispext bit when a
route is enabled. T602x never wrote it, so dpin0 was selected with
no source into the ACIO analog PHY.

0083: set 0x050 on dpin enable. After `request_display` resets pmgr
0x25, deselect and select the dpin mux again.

Keep skip lpdptxphy, unit 0, unk `0x100`. No ATC AUX. No
`core+0x10`.

Load with hub unplugged. Plug USB-C Right only after eDP-1 is up.

Watch: `t602x dpin0` `050=` not zero, `reselect dpin after nub`,
`SET_LINK_RATE`, analog `+0x18`, DP IN `DPRX`.
