# ACIO RC 0x4018 — 2026-09-21 0054 boot

Hyprland: eDP-1 only. Tunnel kept, DPRX=0. Do not `echo 2` on 0054
(that re-applies tunables again).

## Analog dump before writes

```
dpin0 @0x4000 (active 0:5)
  +0x00=80000000   empty/status, same on idle dpin1
  +0x18=00000017   live FSM — only on the active adapter
  +0x40=1 +0x48=1  tunable enables already applied at ACIO start

dpin1 @0x8000 (idle 0:6)
  +0x00=80000000
  +0x18=00000004
```

`+0x00=0x80000000` is not a start register. Pulsing bit 0 there is wrong.

## Tunable reapply clobbered analog

0054 default re-applied `apple,tunable-rc` on the live block. `+0x18`
went `0x17 → 0x80000000`. No tunable at 0x4018; nearby analog writes
reset the FSM. DPME (CS8=40000000) did not set DPRX.

## 0055

Do not re-apply analog tunables. Drive `analog+0x18` only:

- if `+0x18==0x80000000`, restore the observed live value `0x17`
- OR `dpin_fsm` (default `0x08`, the missing bit in `0x17`)

```
echo 0x08 > /sys/module/thunderbolt_apple/parameters/dpin_fsm
echo 1 > /sys/module/thunderbolt_apple/parameters/dpin_aux
```
