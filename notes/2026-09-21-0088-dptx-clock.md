# 0088 USB4 DPTX pixel clocks

The tunnel stays as it is. This turns on the transmitter clocks
in the USB-C PHY: DPRX/DPTX PCLK enables and lane reset release.
SS lanes stay in USB4. The lpdptx AUX block is not written.

`appledrm.usb4_dptx=1` after boot does that, reselects dpin, and
asserts HPD. Default is 0.

## Boot result

eDP-1 stayed on. Tunnel stayed up (`VE=AE=HPD=1`, `DPRX=0`).
Hyprland is still eDP-1 only.

```

USB4 DPTX clocks on (no lane switch, no AUX)
USB4: DPTX clock phy_set_mode 0
```

The ATC PHY pixel clocks are not the crossbar write clock. `800`
stays 0 and there is no `SET_LINK_RATE`.
