# 0085 hold post-nub set_hpd for 8s, no ATC AUX

0084: `DCPDPDevice` starts, ATC AUX returns 0, AFK `set_hpd`
returns -110 at 1s. Firmware's own start timer is 5s, then
message `0xe0115022`, APCALL 22/24, detach. Analog `+0x18=0x17`.

The 1s AFK abort happens while that start is still running.
0085 does not enable ATC AUX (0079 analog `0x1017`). The second
`set_hpd` waits 8s so the call stays open across the 5s timer.

Load hub-unplugged. Plug USB-C Right only after eDP-1 is up.

Watch: `set_hpd after nub 8s`, `DCPDPDevice`, `SET_LINK_RATE`,
analog `+0x18`, DP IN `DPRX`. eDP must stay on.
