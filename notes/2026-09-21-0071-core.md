# 0071 USB4 DPIN CORE=1 — dpin0 tunnel input

0070 target `0x9000` (CORE=0 ATC=0 DPIN=1) is an AFK remote port.
Firmware DPTXController has no device for it.

2022 DCP traces of USB4 tunneling used CORE=1 and CORE=2 as
ATCPHY_INPUT on one Type-C port (two tunnels max). dpin0 / host
adapter `0:5` is CORE=1. Target becomes `0x9001`.

Still: validate + connect(supports_hpd=true) + set_hpd. ATC=0.
No request_display. No lpdptxphy `core+0x10`. If CORE=1 validate
fails, try CORE=2 (`0x9002`). `appledrm.usb4_core=2` forces that
order.

Look for:

```
DPTX validate target=0x9001 core=1 atc=0
USB4: analog DPIN validate core=1 atc=0: 0
USB4: analog DPIN connect core=1 atc=0 HPD: 0
USB4: analog DPIN set_hpd: 0
```

Success: `SET_ACTIVE_LANE_COUNT` lanes>0, DP IN DPRX=1, Hyprland
sees the VMM7100 beside eDP-1. Hub keyboard still works.
