# 0086 keep dcpext run mode 2

`setup_video_limits` on a secondary DCP with no timing steps the
pipe from run mode 2 to 0 and disables the device. That happens
before USB4 HPD. The crossbar enable is already set and DPTX
write-clock status `0x800` stays 0, so `DCPDPDevice` dies at 5 s.

0086 does not call `setup_video_limits` on `apple,dcpext`. The
internal panel still does. No `iomfb_poweron`, no lpdptxphy
`core+0x10`, no `/dev/mem`.

The crossbar logs `t602x <mux> clk:` with `000/800` and `020/820`
after each switch. Success is `800` non-zero, then
`SET_LINK_RATE`, DPRX=1, and a second Hyprland monitor. eDP-1
must stay on.

Do not read display or PMGR registers through `/dev/mem`. That
hard-reset this machine twice (no panic, PMU still 0 panics).
