# 0086 keep dcpext run mode 2 — did not

eDP-1 stayed on. Hyprland is still eDP-1 only. Hub and VMM7100
came up. Tunnel kept. `DCPDPDevice` still died at 5 s
(`0xe0115022`). No `SET_LINK_RATE`.

Firmware calls `setup_video_limits` itself inside `start_ios_gated`
before Linux can skip it:

```
setup_video_limits called on secondary display with no timing set
set_device_enabled 1 -> 1
dcpext: skip setup_video_limits (keep run mode 2)
set_run_mode 2 -> 1 -> 0
set_device_enabled 1 -> 0
```

Crossbar `70304c000` after dpin0 -> dispext1:

```
000=00000004 800=00000000
020=00000001 820=00000000
024=00000110 81c=00000110
```

Skipping the Linux RPC does not keep run mode. The pipe is off
before the crossbar switches, and `0x800` stays 0.

Do not read display or PMGR registers through `/dev/mem`. That
hard-reset this machine (no panic logged). The `t602x clk` line
is the safe readout.
