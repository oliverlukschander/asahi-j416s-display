# 0073 GET_SUPPORTS_HPD on USB4 analog DPIN

0072 CORE=1 `request_display` powered a nub and ACTIVATEd, then
22/24 DEVICE_NOT_STARTED. `GET_SUPPORTS_HPD` returned 0 (old Type-C
USB4 rule). Connect already used `supports_hpd=true` and `set_hpd`
returned 0.

Advertise HPD (`GET_SUPPORTS_HPD=1`) so firmware uses the HPD path
instead of waiting for a PHY that never starts.

Boot: `GET_SUPPORTS_HPD 1 usb4=1`, nub powered, ACTIVATE, **no 22/24**.
Analog timeout `+0x18=0x1017` (bit 12 latched). DPRX=0. `set_hpd`
ran before `request_display`, so the nub never saw HPD.

0074: `set_hpd` after `request_display` / ACTIVATE.
