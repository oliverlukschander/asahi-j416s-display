# 0077 USB4 analog bind on RemotePort unit 1

0076 `0x9041` powered the nub then DEACTIVATEd. 0073 `0x9001` on
port 0 ACTIVATEd with no SET_LINK_RATE.

dcpext has two `AppleDCPDPTXRemotePort` services (channel 1 = unit
0, channel 3 = unit 1). Sven's USB4 traces used both epics. Bind
CORE=1 ATC=0 on unit 1.

Boot: `bind port=1 (unit 1)`, `0x9001` validate/connect/set_hpd 0,
then APCALL 18/10 and **DEACTIVATE**. Analog `+0x18=0x1016`. DPRX=0.

Closed: RemotePort unit 1 DEACTIVATEs. Unit 0 (0073) ACTIVATEs.

0078: bind unit 0 again.
